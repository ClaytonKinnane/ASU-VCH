# История изменений

## Не выпущено

### Добавлено

- начальная структура проекта;
- главная страница с вкладками входа и регистрации;
- первая тема оформления `asu-blue`;
- базовая документация проекта и среды;
- правило выдачи абсолютных прав первому зарегистрированному пользователю;
- конфигурация Open Server Panel 6.5.1 для домена `asu-vch.local`;
- безопасный сценарий локального развертывания `deploy\Deploy-Local.ps1`;
- подробная документация разделения Git-клона и каталога веб-сервера.

### Изменено

- файлы темы при развертывании публикуются в `public\themes`;
- главная страница использует публичные URL ресурсов темы;
- локальный клон больше не рассматривается как корень веб-сервера.

### Ограничения текущей версии

- формы работают только как интерфейсный прототип;
- база данных не подключена;
- регистрация, авторизация и управление доступом не реализованы;
- сценарий развертывания требует локальной проверки в Open Server Panel 6.5.1.
