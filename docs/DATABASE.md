# База данных

## Общие требования

- СУБД: MySQL 8.4.
- Все рабочие данные сайта должны храниться в базе данных.
- Структура базы данных должна создаваться и изменяться контролируемыми миграциями.
- Кодировка и сравнение строк должны обеспечивать корректную работу с русским языком.
- Учетные данные подключения не должны храниться в репозитории.

## Статус

Схема базы данных еще не разработана. Проектирование таблиц пользователей, ролей, разрешений, настроек, тем и журнала аудита будет выполнено отдельной задачей после согласования модели данных.
