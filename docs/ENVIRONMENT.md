# Среда разработки и запуска

## Целевая среда

- Windows 11
- Open Server Panel 6.5.1
- Apache
- MySQL 8.4
- PHP 8.5
- минимально поддерживаемая версия PHP: 8.3
- PowerShell 5.1

## Локальный клон

Тестовый клон располагается в:

```text
C:\Project\ASU-VCH
```

На веб-сервер должна копироваться только директория и файлы, необходимые для работы сайта. На текущем этапе корнем сайта следует назначить каталог `public`.

## Первый запуск

1. Клонировать репозиторий в `C:\Project\ASU-VCH`.
2. В Open Server Panel создать домен, направленный на `C:\Project\ASU-VCH\public`.
3. Выбрать PHP 8.5 и Apache.
4. Перезапустить Open Server Panel.
5. Открыть созданный локальный домен.

Подключение MySQL будет добавлено отдельной задачей.
