# О проекте

## Наименование

**Полное:** Автоматизированная система учета военнослужащих «Войсковая часть».

**Краткое:** АСУ-ВЧ.

## Назначение

АСУ-ВЧ предназначена для автоматизации учета военнослужащих и связанных с ними данных в рамках войсковой части.

## Основные требования

- Репозиторий `ClaytonKinnane/ASU-VCH` является единственным источником истины.
- Все рабочие данные сайта должны храниться в базе данных.
- Публичная часть и административная панель должны поддерживать независимые темы оформления.
- Дополнительные библиотеки, отсутствующие в стандартной поставке Open Server Panel 6.5.1, допускаются только после обоснования и согласования.

## Текущее состояние

Создана первая версия главной страницы с формами входа и регистрации. Серверные обработчики авторизации, регистрация пользователей и подключение к базе данных пока не реализованы.
