# О проекте

## Наименование

**Полное:** Автоматизированная система учёта военнослужащих «Войсковая часть».

**Краткое:** АСУ-ВЧ.

## Назначение

АСУ-ВЧ предназначена для автоматизации учёта военнослужащих, управления доступом, нормативных справочников и связанных процессов войсковой части.

Проект развивается инкрементально. Реализация конкретных воинских частей, фактической организационной структуры, личного состава и документов выполняется только после отдельного архитектурного проектирования и утверждения границ данных.

## Основные требования

- Репозиторий `ClaytonKinnane/ASU-VCH` является единственным источником истины.
- Код и документация изменяются в отдельных ветках GitHub.
- Локальный клон используется только для синхронизации, deploy и тестирования.
- Все рабочие данные приложения хранятся в MySQL; секреты и локальные параметры в Git не помещаются.
- Материальные изменения проходят Architecture → Specification → Review → Approval до реализации.
- Merge выполняется только после тестирования и отдельного явного разрешения владельца проекта.
- Feature-ветки не удаляются без отдельного разрешения.
- Интерфейс поддерживает тёмно-синюю и светлую синюю темы.

## Реализованное состояние

В `main` реализованы:

### Платформа и безопасность

- установка приложения и последовательные миграции 001–008;
- первичное создание единственного владельца системы;
- отключение bootstrap-регистрации после создания владельца;
- вход, выход, защищённые сессии и CSRF;
- RBAC с четырьмя системными ролями и 19 системными permissions;
- обязательная смена временного пароля;
- создание, подтверждение, редактирование и блокировка пользователей;
- отклонение пользователя с обязательным основанием и аудитом;
- архивирование и восстановление пользователя с аудитом;
- тематические страницы отказа и результата операций.

### Темы

- доверенный статический реестр тем;
- глобальное хранение активной темы в БД;
- безопасный fallback;
- темы `asu-blue` и `asu-light-blue`;
- desktop-приёмка обеих тем.

### Справочники

- стартовая страница справочников;
- read-only нормативный справочник составов военнослужащих и воинских званий;
- read-only нормативно-методический справочник типов организационных элементов;
- поиск и фильтры;
- owner-only доступ через `system.*.*`.
