# Темы оформления

## Назначение

Система должна поддерживать темы для:

- всего сайта;
- только публичной части;
- только административной панели.

Публичная часть и административная панель могут использовать разные темы.

## Первая тема

- Название: **АСУ — Синяя**
- Идентификатор: `asu-blue`
- Каталог: `themes/asu-blue`

Основные цвета:

- фон: `#131e30`;
- стеклянные плитки: `#0370a9` с прозрачностью;
- рамка плиток: `#18acea`;
- кнопки: `#17a58b`;
- рамка кнопок: `#35d492`.

На текущем этапе тема подключается напрямую. Механизм выбора темы из базы данных будет разработан отдельной задачей.
