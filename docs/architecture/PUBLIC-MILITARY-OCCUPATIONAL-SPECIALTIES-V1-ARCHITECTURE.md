# Публичные сведения о ВУС — Architecture v0.1

## Статус

OWNER-APPROVED. Реализация разрешена после baseline `99f9f283768ca418fb7ff86d55b7d73e7a6c3510`.

## Решение

Создаётся отдельный source-centric read-only каталог. Одна запись представляет одно атомарное раскрытие одного официального источника. Каталог не является полным перечнем ВУС, не ведёт персональный воинский учёт и не реконструирует закрытые сведения.

## Границы MVP-1

- 9 version-owned таблиц и 26 lifecycle triggers;
- 5 нормативных связей, 4 snapshots официальных страниц;
- 3 сегмента структуры кода, 6 публичных контекстных областей;
- 3 локальные категории программ подготовки;
- 2 нормативных примера и 15 атомарных программ;
- owner-only, GET-only, read-only UI;
- отсутствуют связи с должностями, званиями, ВВСТ и гражданами;
- отсутствуют import, upload, scraping и runtime HTTP requests.

Lifecycle: `building → published → superseded`. Published и superseded данные неизменяемы.
