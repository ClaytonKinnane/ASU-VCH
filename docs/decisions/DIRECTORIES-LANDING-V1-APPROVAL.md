## Утверждённый scope

- активная плитка `Справочники` на `/admin/content.php`;
- новая owner-only страница `/admin/directories.php`;
- две статичные плитки: `Подразделения` и `Воинские звания`;
- статус `В разработке` для обеих плиток;
- кнопка `К контенту`;
- использование существующих компонентов обеих тем;
- повторное использование существующего hover-контракта `dashboard-tile` для активной плитки;
- автоматические структурные и syntax checks;
- отдельная desktop-визуальная приёмка пользователем.

## Ограничения

Не входят:

- БД, migration и данные;
- CRUD;
- поиск, фильтрация и сортировка;
- новые permissions и изменение RBAC;
- мобильное тестирование;
- merge без отдельного явного разрешения.
