## 4. Утверждённые решения

- справочник хранит общие типы, а не конкретные подразделения;
- плитка называется `Организационные элементы и подразделения`;
- страница называется `Типы организационных элементов`;
- маршрут: `/admin/directories/organizational-elements.php`;
- доступ owner-only через `system.*.*`;
- новые permissions не добавляются;
- каталог read-only;
- каталог версионируется целиком;
- типы и организационные классы разделены;
- тип может относиться к нескольким классам;
- универсальная жёсткая иерархия типов отсутствует;
- фактические структуры и подчинённость исключены;
- migration: `008_organizational_element_types_directory.sql`;
- добавляются 7 таблиц;
- первоначально создаются 4 источника, 6 классов, 28 типов и 32 связи тип–класс;
- `боевой пост` и `смена` исключены;
- организационный статус вычисляется по классам;
- `БЧ` является официальным сокращением типа `боевая часть`;
- checker проверяет опубликованные assets через `ThemeRegistry`;
- мобильное тестирование исключено.
