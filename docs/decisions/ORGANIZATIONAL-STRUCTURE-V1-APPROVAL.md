# Approval: фактическая организационная структура воинской части v1

## Решение владельца проекта

> Утверждаю Architecture / Specification версии 0.2 и результаты Formal Review для инкремента «Фактическая организационная структура воинской части v1». Разрешаю создать отдельную feature-ветку от актуального main и перейти к документации и реализации в пределах утверждённого scope. Merge и удаление веток не разрешаю без отдельного явного согласования.

## Зафиксированный scope

- versioned adjacency-list дерево;
- стабильные идентичности элементов;
- документы-основания без файлов;
- `draft / approved / active / superseded / cancelled`;
- RBAC из шести permissions;
- предметная append-only история;
- permission-aware навигация;
- три темы;
- desktop/mobile.

## Ограничения Approval

Approval не разрешает Pull Request, merge, удаление веток или заявление PASS без фактического тестирования. Реализация фиксируется непосредственно в GitHub feature-ветке; локальная машина используется только для deploy и Testing. Pull Request выполняется после локального Testing и Test Report согласно процессу проекта.
