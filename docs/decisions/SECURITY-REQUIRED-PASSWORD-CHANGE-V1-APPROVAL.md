# SECURITY REQUIRED PASSWORD CHANGE V1 — APPROVAL

Статус: Approved
Дата: 2026-07-25
Ветка: `feature/required-password-change`

## 1. Утверждено

Утверждены Architecture/Specification инкремента обязательной смены временного пароля.

Пользователь явно разрешил реализацию формулировкой:

> Утверждаю Architecture/Specification Security Required Password Change v1 и разрешаю реализацию

## 2. Утвержденный объем

- центральное ограничение административных маршрутов при `must_change_password = 1`;
- redirect после входа на обязательную форму;
- маршрут `/account/change-password.php`;
- проверка текущего пароля;
- политика нового пароля 10–128 символов, минимум буква и цифра;
- запрет повторного использования текущего пароля;
- транзакционное обновление password hash;
- снятие `must_change_password` и `is_temporary`;
- регенерация session ID и CSRF-контекста;
- адаптивный интерфейс;
- автоматизированная и ручная проверка.

## 3. Утвержденные ограничения

Не входят:

- добровольная смена пароля без обязательного флага;
- административный сброс;
- восстановление забытого пароля;
- история паролей;
- отзыв других сессий;
- MFA;
- срок действия пароля;
- email-уведомления.

## 4. Миграции

Новая миграция не создается. Используются существующие поля таблицы `users`.

## 5. Разрешение процесса

Разрешен переход к этапам Implementation → Testing → Commit → Push → PR. Merge потребует отдельного явного разрешения после review и приемки.
