# SECURITY USER CARD EDIT V1 — APPROVER DISPLAY APPROVAL

Статус: Approved
Дата: 2026-07-25

## Утверждено

В блоке «Доступ» карточки пользователя добавить поле `Кем подтвержден`, используя существующие данные `approved_by` и связанную учетную запись подтверждающего.

## Утвержденные правила

- подтвержден пользователем: отображаемое имя и логин;
- системное подтверждение: `Системная операция`;
- пользователь не подтвержден: `Не подтвержден`;
- поле доступно только владельцу системы и администратору;
- блок аудита сохраняется;
- миграция не создается.

## Отдельный последующий инкремент

Операция отклонения и сведения `Кем отклонен`, дата и основание отклонения не входят в данное дополнение. Они требуют отдельного цикла Architecture → Specification → Review → Approval.

## Основание утверждения

Пользователь утвердил разделение текущего дополнения и будущего инкремента аудита отклонения в рабочем диалоге проекта.
