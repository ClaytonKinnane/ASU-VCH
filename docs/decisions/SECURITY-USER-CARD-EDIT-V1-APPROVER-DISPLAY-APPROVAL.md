## Утверждено

В блоке «Доступ» карточки пользователя сведения о статусе подтверждения и подтверждающем объединяются в одном поле `Подтверждение`.

Отдельное поле `Кем подтвержден` удаляется.

## Утвержденные правила

- подтвержден пользователем: первая строка `Подтвержден`, вторая строка — отображаемое имя подтвердившего как ссылка на его карточку;
- логин подтвердившего в этом поле не выводится;
- системное подтверждение: первая строка `Подтвержден`, вторая строка `Системная операция` без ссылки;
- pending-пользователь: только `Ожидает подтверждения`;
- rejected-пользователь: только `Отклонен` до реализации отдельного аудита отклонения;
- поле доступно только владельцу системы и администратору;
- блок аудита сохраняется;
- миграция не создается.

## Отдельный последующий инкремент

Операция отклонения и сведения об отклонившем, дата и основание отклонения не входят в данное дополнение. Они требуют отдельного цикла Architecture → Specification → Review → Approval.

После появления `rejected_by` отображаемое имя отклонившего должно выводиться второй строкой того же поля `Подтверждение` со ссылкой на карточку.

## Основание утверждения

Пользователь уточнил и утвердил представление в рабочем диалоге проекта: субъект подтверждения или отклонения не должен занимать отдельное поле; достаточно отображаемого имени со ссылкой внутри поля статуса.
