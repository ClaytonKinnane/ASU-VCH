# Security / Users List v1 — Approval

Статус: **Approved**  
Домен: **Security**  
Связанный дизайн: `docs/design/SECURITY-USERS-LIST-V1-DESIGN.md`

Утверждено без изменений:

1. `/admin/users.php` становится рабочим списком учетных записей.
2. Доступ требует `security.users.view`, а `system_owner` получает его через `system.*.*`.
3. Реализуется корректная многоролевая авторизация.
4. Поиск выполняется по логину, отображаемому имени и email.
5. Поддерживаются фильтры `all`, `active`, `blocked`, `archived`, `temporary`, `password_change`.
6. Размер страницы фиксирован: 25 записей.
7. Пользователь только с ролью `viewer` не получает email и дату последнего входа в HTML.
8. На мобильных устройствах таблица преобразуется в карточки без горизонтального переполнения.
9. Создание, редактирование и открытие карточки пользователя остаются за пределами этого инкремента.

Реализация разрешена после этого решения.
