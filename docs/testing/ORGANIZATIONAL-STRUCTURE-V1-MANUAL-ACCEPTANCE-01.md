## Выявленные UI-недочёты

### UI-01. Browser autofill нарушает палитру темы

При заполнении полей сохранёнными браузером данными фон input становится белым и визуально выбивается из активной темы.

### UI-02. Неверный курсор у элементов раскрытия формы

При наведении на подписи наподобие «Изменить карточку» и «Добавить документ-основание» отображается текстовый курсор вместо указателя интерактивного элемента.

### UI-03. Нативные disclosure-маркеры не соответствуют интерфейсу

Нативные треугольники `<summary>` требуется заменить визуально оформленными theme-aware кнопками:

- обычное раскрытие формы — тематическая кнопка с chevron;
- добавление — тематическая кнопка со знаком `+`;
- редактирование — тематическая кнопка со значком карандаша;
- опасные действия — danger-вариант тематической кнопки.

### UI-04. Нативный чёрный значок календаря не соответствует теме

В date-полях требуется сохранить нативный date picker, скрыть стандартный чёрный индикатор и отобразить собственный theme-aware значок календаря.
